# Архитектура проекта

## Тема

Поиск оптимальных коэффициентов сжатия для моделей машинного обучения.

**Цель:** найти лучшие коэффициенты сжатия так, чтобы точность на тестовой
выборке не падала ниже порогового значения.

**Коэффициент сжатия** = `размер датасета (байты) / размер модели (байты)`,
где размер модели — это размер сохранённого `.pth` файла.

## Подход

Итеративно, от простого к сложному:

1. MNIST + полносвязная модель
2. MNIST + свёрточная модель
3. дальнейшие улучшения

«Сжатие» на текущем этапе достигается изменением **архитектуры** модели
(ширина / глубина). Модель параметризуется одним размерным аргументом, что
позволяет перебирать варианты единообразно.

Прунинг и дистилляция — отложены. Алгоритм поиска оптимума (перебор по сетке /
бинарный поиск) — отложен.

```

├── requirements.txt          зависимости

├── ARCHITECTURE.md           этот файл
├── models/                   определения моделей
│   └── fc.py                 параметризованная полносвязная модель
├── datasets/                 данные
│   ├── loader.py             загрузка MNIST через torchvision
│   └── data/                 хранилище скачанных данных
├── core/                     общий код
│   ├── train.py              обучение модели
│   ├── inference.py          оценка модели на тестовой выборке
│   └── sizes.py              размеры моделей и датасетов в байтах, коэффициент
├── saved_models/             сохранённые .pth чекпоинты
└── execution_scripts/

```

## Ответственность модулей

- `models/fc.py` — полносвязная сеть с настраиваемым размерным параметром.
- `datasets/loader.py` — скачивание MNIST и подготовка train/test даталоадеров.
- `core/train.py` — цикл обучения модели на train-выборке.
- `core/inference.py` — прогон обученной модели на test-выборке, расчёт точности.
- `core/sizes.py` — измерение размера `.pth` и датасета в байтах, расчёт
  коэффициента сжатия.
- `execution_scripts/run.py` — связывает всё вместе: перебирает размеры модели,
  для каждого обучает, оценивает, сохраняет, считает коэффициент.

## Сценарий эксперимента

```
для каждого размера модели S:
    модель = создать_модель(S)
    обучить(модель, train)
    точность = оценить(модель, test)
    сохранить .pth → измерить размер в байтах
    коэффициент = размер_датасета / размер_модели
    вывести: S, точность, размер модели, коэффициент, пройден ли порог
```

Результаты на текущем этапе выводятся в консоль.
